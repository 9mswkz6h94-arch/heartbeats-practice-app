# Chordillo-aligned companion proposal — V2

**Status:** Accepted app-local cast direction; three-format V1 complete and visually QA'd

**Accepted by:** Jonathan, 2026-09-07

**Scope:** Musical Zoo character art only

**Canonical status:** Does not define the shared Rainbow Heart illustration language

## Direction

Chordillo is the visual quality anchor for the Musical Zoo cast. The V2 proposal keeps each animal/instrument identity while replacing the V1 library's strict four-color icon treatment with:

- rounded, dimensional creature anatomy;
- expressive, readable eyes and warm neutral poses;
- dark stepped pixel outlines with clustered highlights and shadows;
- disciplined multi-tone palettes rather than flat four-color fills;
- instruments integrated into each creature's anatomy;
- distinct silhouettes that remain recognizable without labels.
