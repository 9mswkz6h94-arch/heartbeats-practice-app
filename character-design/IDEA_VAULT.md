# Musical Zoo idea vault

This is the parking place for promising characters outside the locked starter trio. Vault entries preserve ideas without expanding current production scope.

## Rules

- An entry is a concept, not an unlock promise or implementation task.
- Do not create production assets, manifests, database records, or app integrations without explicit approval.
- Check new ideas against existing musical roles, practice virtues, silhouettes, palettes, and instrument anatomy to avoid reskins.
- Moving an idea into production requires a stable ID, a progression purpose, and a complete character packet under `characters/<id>/`.
- Founding Friends remain separate from this vault and retain all existing progress.
