# Musical Zoo full-art stickers

This folder holds large transparent sticker masters. These are expressive interpretations of approved characters, not upscaled pixel sprites.

## Riffin Celebrate V1

- **Master:** `riffin-sticker-celebrate-full-v1.png`
- **Canvas:** 1305×1305 transparent PNG
- **Web derivative:** `../../public/characters/riffin/sticker-celebrate-full-512-v1.png`
- **Status:** approved by Jonathan on 2026-09-05 and referenced by Riffin Character Version 3
- **Reference inputs:** `../sprites/riffin-64x64-v2.png`, `../sprites/riffin-sticker-celebrate-v2.png`, and `../sprites/riffin-v2-final-review-board.png`
- **Generation record:** `riffin-sticker-celebrate-full-v1-prompt.md`
- **Locked identity preserved:** tall fox ears, integrated acoustic-guitar resonator torso, one sound hole, exactly three belly strings, and a guitar-neck tail with exactly three tuning pegs
- **Celebrate read:** one paw strums, one paw lifts, and exactly three music notes float around Riffin
- **Safety:** no text, score, trophy, rank, comparison, or pressure cue

The built-in image generator created the illustrated candidate from the approved Riffin references. A background-extraction pass removed a baked checkerboard while preserving the artwork and warm-cream die-cut edge. The final project master was padded—not redrawn—to a square transparent canvas, then exported as a 512×512 web derivative.
